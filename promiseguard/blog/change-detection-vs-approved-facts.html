Change detection vs. approved-fact checks: what agencies actually need

PromiseGuard blog · Oct 31, 2026

Website change-detection tools answer one question: did this page change since last time? That's useful, but it's not the question a client asks when a customer calls the wrong number.

Two different questions

Change detectionApproved-fact check
QuestionDid anything change?Does the page match what the client approved?
Catches a price that's been wrong for a yearNo, it never changedYes, it doesn't match the approved price
Noise from harmless editsCan be highOnly flags rules you defined
Setup effortLow: add a URLHigher: write and approve the facts

When to use which

Use change detection to notice that something moved. Use approved-fact checks when accuracy is what you're accountable for: prices, phone numbers, booking links and claims. The setup cost is real: someone has to write the facts down. That step is also what makes the client conversation easier: you're both working from a list they signed off on.
